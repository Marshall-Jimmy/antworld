# Antworld 蚂蚁世界

蚁群信息素(stigmergy)仿真: 数千只蚂蚁靠信息素轨迹、路径积分与个体性格涌现觅食网络。

## 跑起来

```bash
npm install
npm run dev        # http://localhost:5300
npm run build      # 产物在 dist/
```

## 玩法

- 工具(F/W/E/P 切换): F=食物(左键点蚂蚁检视 / 空地放食物), W=画墙(左键拖动画障碍), E=擦墙,
  P=捕食者(左键放置/移除, 半径 45 内蚂蚁被捕杀); `X` 清除全部墙。
- 右键: 移除食物 / 拖动平移; 滚轮缩放。
- 键盘 `1/2/3/4` = 0.125/1/4/64 倍速, `0` 暂停。
- 键盘 `R` = 立刻排一场雨(自带 40s 雨前低压, 抢收过程看得见), `N` = 把内源钟推半周期(昼↔夜)。
- 右侧面板实时调参, 11 个夹子(世界/感知/转向/置信度/运动·记忆/觅食经济/能量·生死/真实感/天气·昼夜/场/画面外观), 默认**全部折叠**,
  只展开「场景与视图」; 一行参数是短名, 完整说明**悬停看 tooltip**; 找不到就用「展开全部」。
- **参数过滤框**(面板最上面那格, 或按 `/` 跳进去): 打参数名/说明里的任意词, 右边实时报 `命中/91`。
  实测 `雨` = 7/91 且只自动展开「天气 / 昼夜」; **清空即完全复原**(连进入过滤前的折叠状态都还原)。
  框里打字不会被当成快捷键(打 `f` 不会切工具), `Esc` 第一下清空、第二下退出输入框。
  「生成新世界」换种子, 「复制分享链接」带走当前参数+种子。
- **场景**(`?preset=`): 默认走廊 / 迷宫(P2.1) / 双源竞争 / 断口剂量 / 饥荒生存(P2.5)。切走时会先撤销上一个
  预设改过的参数, 所以 A→B→A 与"从没换过预设"逐位相同; 预设只改布局与行为参数, **不改渲染参数**。
- **跟拍**(`G` 或按 F 点一只蚁, 右键取消; `?follow=1` 开局跟拍): 相机跟随 + 轨迹面包屑 + 个体事件时间线
  (出发/发现食物/到家卸货/弃货/迷路/死亡), 一只蚁的完整故事讲得出来。
- **统计曲线**(`M`): 卸货率、负重蚁数、空手返巢、弃货、被捕杀、种群、田外存粮 的最近 60s 滑窗 sparkline
  (后两条现在是平线, 它们是 P2.5 能量与生死的读数口)。
- **录像**(`V`): 主画布与覆盖层合成成一条 webm, 再按一次停止并自动下载(帧率=真实渲染帧率, 不做假流畅)。
- **HUD 详略**(`H` 三档, 出厂最简那档只有 2 行): 第一行 fps/后端/倍速/画质, 第二行种群与经济;
  往上还有 sparkline 与全量账目。所有时间读数走**仿真内时钟** —— 64× 倍速下与墙钟差 64 倍, 看曲线别按手表。
- **画质**(`Q` 或面板按钮): 出画分辨率三档循环 100% → 75% → 55% → 100%, 100% 是出厂画面(逐像素)。
  它是唯一砍得动 GPU 填充率的开关, 适合**大窗口/高分屏**或核显吃不住时按; 当前档会写进地址栏
  `?renderScale=` 并随分享链接带走, HUD 上标 `画质 75%` 这类字样提醒你画面被降过。
- **倍速是否名副其实看 HUD 那行「达成 %」**: 它是实测仿真步/秒 ÷ 该倍速需要的步/秒(64× = 3840 步/秒)。
- **画面三档开关**(`?inkMode=` `?antStyle=` `?foodLook=`): 白纸墨色 / 黑壳工蚁 / 会被啃的食物, 出厂全开;
  三个都关 ⇒ 画面**逐字节**退回 P2.3.4 的黑底加光版(SHA256 已证)。粗细另有三支: `antLen` 体长(屏幕像素)、
  `antVar` 个体差异、`trailInk` 走廊墨色浓淡。
  跑不到 100% 说明本机单核算力到顶, 不是循环漏了步 —— 高倍速下画面会主动降帧保仿真。实测单价:
  **ms/步 ≈ 0.163 + 0.000587 × 蚁数**(出厂 5000 蚁 ≈ 3.1 ms ⇒ 上限约 5×; 想要 16× 得降到 ≤1500 蚁)。
  所以倍速档不是免费的: 蚁越多, 能买到的倍速越低。
  `?stepBudgetMs=24` 可以把一帧里给仿真的墙钟预算调大/调小(默认 12 ms, ≥4× 自动抬到该档渲染周期)。

## 观察什么

- 蚂蚁从乱走到成路: physarum 三触角寻路(Jones 2010)如何把噪声刻成走廊。
- 食物耗尽后的行为: 觅食超时返巢 + 路径信任(P1.9), 死点自动消散。
- 障碍与绕行(P2.1): 画一道墙隔开巢和食物, 看蚁群绕经缺口重新成路; 信息素不渗墙,
  路会贴着墙脚走。K_wall=0 可对比"纯物理硬挡"与"主动避让"的吞吐差。
- 捕食者与避险(P2.2): 按 P 在主路上放一只捕食者——圈内的蚂蚁被捕杀, 死亡原地喷溅
  报警信息素(红色, 比轨迹挥发快一档), 闻到的蚂蚁掉头就跑。看路线怎么被群体"绕"出来:
  逃生的蚂蚁沿逃逸曲线把改道 skirt 一条条铺出来, 几分钟内主流量改走圈外;
  移除捕食者(P 再点一下), 报警云几十秒散尽, 路线很快合拢回来。
  「报警感知阈值」「避险转向」(感知/转向组)与「报警信息素挥发/喷溅量」(场组)可调。
- 昼夜与天气(P2.3): 开「昼夜节律强度」后画面色温随光照走(午夜冷蓝→晨昏暖金→正午白), 而**行为**
  跟着蚂蚁体内的钟走——「内源钟相位」0=昼行、0.5=夜行, 同一个环境里两个物种预设完全反相(正午
  4684 只在外 vs 深夜 123 只)。真实感来自三条独立通道: 温度窗口(10–45°C 之外冷麻痹, 出不了巢)、
  雨前低压抢收(起雨前 40s 出巢率与搬运速度同时飙升, 雨一落地立刻收场)、雨风冲刷(轨迹场指数
  衰减加速, 不是一步抹平)。按 R 看一场完整的风暴: 涌出→急雨停摆→雨后重建。
- 看画面**读得出结构**而不是发光一团(P2.3.1): 「色阶曲线」=0 时高浓度走廊整片烧成纯白,
  宽度/分叉/强弱全丢; =1(默认)是对数上肩的有界色阶——「色阶参考浓度」那一格=半亮, 其上每
  翻倍亮一档, 256× 才到白热上限, 所以最热的干线和它旁边的支路是两种颜色。同一份场数据前后对比:
  纯白像素 5.71%→0.00%, 觅食网内可辨亮度级数 1→134。HUD 第一行自报「渲染 WebGL2」或「Canvas2D(兜底)」。
- **光污染 II（P2.3.2）**: 让"发光一坨"消失的两条腿。①「扩散权重」出厂 0.06→**0.02**——这是推导值不是手感值:
  信息素云的衰减长度 ℓ=√(D/λ) 必须 ≤ 触角长度 26 单位, 否则场里存着蚂蚁根本读不到的信息(实测吞吐 **+7%**、
  失败行程 **−18%**)。②「自适应曝光」(场组, 默认开): 色阶参考浓度跟着**蚂蚁脚下实际闻到的剂量中位数**走,
  只收光不加光——过曝的管饱场景雾可见半径 9.3→**2.3 格**、离路死光 38.7%→**8.2%**, 而常规玩法画面逐位不变。
  `autoPeak=0`(退回钉死的滑杆) 与 `diffuseWeight=0.06`(退回旧扩散) 各自都能单独回退。
- **个体路线记忆(P2.4)**: 每只空手出门的工蚁把自己的路记成一串航点, 回到巢里卸货时才"提交"成正式路线;
  闻不到走廊时(夜里蒸发、被雨冲平、被捕食者撕断)改走自己记得的那条, 连续扑空两次就废弃。
  **最好看的时刻是黎明前**——集体走廊被夜削到百分之一, 开了记忆就不必全群从零重踩。
  用 `?inspect=N` 跟拍第 N 只蚁: **青色虚线**是它记住的航点链、空心圆是它下一个要奔的点, 读数行给出
  "几航点 / 多长 / 走到第几点 / 扑空几次", 旁边那条橙色是它这一趟**实际走过的轨迹**——两者在哪里分开,
  就能在哪里看见"记忆在替信息素做主"。记忆要攒够趟数才成熟, 所以配合 `?food=5000` 管饱(默认那块
  200 单位食源在千只蚁下十几分钟就被搬空, 那是观察条件不是作弊)。`K_mem=0` 退回纯信息素。
- **路线成熟度门(P2.3.3)**: 把走廊做窄做准之后冒出来的一条隐性债——**从没被走通验证过的私人路线,一提交就拿满权威**。
  真实蚁的沿线保真**不随访食经验即时调制**(跟着走是硬连线的,是"反复走同一根线"反复走出来的),所以能动的自由度
  不是权重常数,而是**验证次数**: 同一条线连续被走通 `K_route` 次才拿满记忆份额,没走够按比例给(出厂 2)。
  效果: 400 蚁小群体建成期**最坏种子**的吞吐 73.4%→**102.5%**、跨种子极差 44pp→15.5pp;
  代价如实记: 集体通道被摘走时的记忆红利 2.88×→2.48×(门是拿红利换稳健)。 `?K_route=0` 逐位退回 P2.3.2。
  面板里它在「运动 / 记忆」组,和「个体路线记忆权重」并排,可以直接拖 0↔2 看建成期的差别。
- **侧抑制背景减除(P2.3.4)**: 光污染第三段。前两轮之后画面还剩一层**空间上的共模雾**——一大片缓变的背景,
  任何蚂蚁都从里面读不出方向, 却和走廊一样占着亮度预算。实测靠曝光压它: 乘数 ×1→×4, 死光只从 5.4% 降到 4.4%,
  走廊可辨级数却从 85 塌到 25 ⇒ **收光这条路到天花板了, 得换坐标**。于是显示量从「这一格有多少信息素分子」
  换成「这一格比**触角够得着的那一圈**强多少」: 显示量 = 浓度 − K×半径 3 格那一圈的均值(半径由触角派生,
  不新增旋钮; 它与薄场信息素云的衰减长度 ℓ=3.14 格撞在同一个数上)。依据是核实过的三条生物学:
  触角叶突触前侧抑制做增益控制(Olsen & Wilson 2008)、侧抑制带来浓度不变性(Kim & Wang 2009)、
  弓背蚁循迹靠触角**跨轨迹边缘**采样(Draft et al. 2018)。出厂 **`lateralK`=0.5**(九次 sim 扫出来的):
  像素层死光 7.6%→**2.9%**、雾半径 R25 2.0→**1.3 格**、走廊路格存活 **100%**、路格八度跨度 1.45×(结构更可读)。
  代价如实记: 常规玩法均亮 0.65×, 且**凡大范围缓变的积累都会变暗甚至消失**(探索网、巢周老堆、雨后均匀场)——
  这是设计意图的另一面, 判据压不住, 靠出图肉眼裁决。纯渲染层 ⇒ `?lateralK=0` 时画面**逐字节**退回上一版
  (SHA256 已证), sim 一个位都没动。面板里它在「场」组, 拖 0↔0.5 就能看见那层蓝雾进出。
- **画面外观（P2.3.5）**: 这一版把「发光」换成了「反射」——纸是暖白的，信息素是**踩出来的土黄→深褐墨渍**，
  蚂蚁是**近黑的虫体**：头/胸/腹三段 + 腹柄细腰 + 膝状触角，放大还有六足与大颚；负重的工蚁**嘴里叼着一粒粮**
  （不再是"全身泛金"）。食源是一粒**会被啃的种子**：搬走多少就小多少，并啃出一个角度正比于已吃掉比例的扇形缺口，
  缺口边缘有啃痕、新茬露浅色内瓤。三条各是一个独立开关，全关即逐字节退回旧画面（`look_check` A1 钉死）。
  为什么值得做：旧画面是 5000 只蚁在 95% 纯黑底上叠成一层**冷蓝噪点**（实测近黑占比 95.4%、冷蓝识别子 2.86%），
  那不是蚁群是电视雪花；换白纸之后近黑 0.0%、冷蓝 0.000%、暖亮底占画面 93.6%。
- **能量与生死（P2.5）**: 面板「能量与生死 (P2.5)」夹子的总开关，或者直接 `?survivalMode=1`。**出厂是关的**
  （关着时仿真与以前**逐位相同**，它是一个可以随时扔开看的新世界）。打开之后：空手也在烧能量、
  负重更贵（真实 3× 自重负载）、到巢从**巢储**取食、能量归零饿死、累计外勤秒走到寿命分布尾部力竭而死
  （巢内不折寿：真实蚁巢内可活数月、开外勤只活几天）、巢储高过「起募存粮」才产新蚁、
  新蚁先在巢里做一段内勤才转外勤、死亡当场留一点会挥发的报警残痕（远小于捕杀喷溅）。
  **看什么**: HUD 第一行变成「种群 存活/上限 · 巢储 · 出生/死亡(饿/竭)」，按 `H` 到最详细那档看三本账
  （入库/取食/产蚁耗/溢出、田外余粮、全群最低能量）；按 `M` 多出两条曲线（种群与巢储，只有开着才出现）；
  点一只蚁可以看到它的能量、累计外勤秒、巢内服务期剩余，还有一个 **id**——它被收尸压缩搬过格子也还是这一只，
  跟拍会一直跟到它死（镜头停下来，故事线上给一个 † 或 ✚）。
  **两个必须先知道的事**: ① 默认走廊那块食源只有 200 单位，5000 只蚁分——**开生死就会缩员**，这是场景与机制的
  量纲不匹配，不是故障；想看「自我维持」要么 `?food=999999999` 管饱、要么用预设。
  ② 饥荒预设（`?preset=famine`）现在**真会饿死人**，但它目前不会「战略性放弃远源」——双源实测反而先放弃
  **近**源（近处还剩 36% 时流量已经搬去远处），因为沉积按负重时长计、集体通道按「线的长度」分配流量，
  而模型还没有「够吃就停」这条门（真实蚁群靠交哺拒绝与 return-rate 招募，已立项 P2.7）。
- 「真实感」组拉 0: 回到整齐划一的程序化蚁群, 对比极明显。

  T8b 是 6/1000 只走不回巢的个体尾巴。判据与阈值一条都没改, 来龙去脉见 METRICS P2.5 §4。
- `node look_check.mjs` **画面外观门禁**(P2.3.5, 58 断言 / 约 22 秒): A1 三档全关逐字节退回出厂图(SHA 登记在文件头),
  A2-A5 白纸/冷蓝消失/蚁体变暗的像素裁决, A6-A10 蚁体形状与「会被啃」的几何判据, A11-A14 **没有 GPU 也能跑**的
  GLSL 静态 lint(实参个数/varying 配对/声明完整/look.js 真的接进了着色器), A16 场 quad 铺满世界 + 混合约定成对,
  Az1-Az4 对照臂(故意造坏着色器与坏 quad, 判据必须报红)。`SUB=pixel,shape,glsl,param` 可分组。
- `backend_check.html` **后端体检页**(浏览器打开): 能力查询 + 逐对 compile/link + `init()` 与 `failReason`。
  它不跑真实蚁群, 只回答一件事——「浏览器里跑的到底是 WebGL2 还是兜底」(P2.3.1 与 P2.3.5 两次静默兜底事故的教训)。
- `node scale_dashboard.mjs` **规模化成本仪表板**(P2.6, 只读 sim + 纯 CPU 微基准, REPS=5 实测 3 分 39 秒)。
  三段各钉一个决策: ① 场与蚁群分开计时(先迁谁) ② 原语 ns 预算 × 调用次数(CPU 还剩多少可挤)
  ③ **跨进程**配对 A/B(每臂一个独立 node 进程, 外加一臂故意慢一倍做**可见性对照**,
  那臂看不见就整段作废)。`MODE=scale|paired|budget` 单跑一段 · `ONLY=target` 只跑目标规模 ·
  `REPS=<n>` 取中位 · `LOAD=<n>` 起自旋线程, 把「历史读数偏慢 = 同机在抢 CPU」这条归因**复现**出来。
  量具文件头不放任何读数(读数只在 stdout, 每次重跑都刷新), 结论倍数由同一次运行量到的数算出。
